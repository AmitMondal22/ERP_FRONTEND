📑 Inventory Management System – API Documentation
🔑 Authentication
POST /api/auth/register

Description: Register a new user (Super Admin, Site Incharge, Project Incharge)

Body:
{
  "username": "John Doe",
  "email": "john@example.com",
  "password": "password123",
  "mobile": "9876543210",
  "userType": "Super Admin",
  "address": "Somewhere"
}

POST /api/auth/login

Body:

{
  "email": "john@example.com",
  "password": "password123"
}


Response: Returns JWT token + user details


📂 Master Data
Project Site

GET /api/project-sites → List all project sites

POST /api/project-sites → Create project site

PUT /api/project-sites/:id → Update project site

DELETE /api/project-sites/:id → Delete project site

Fields:
projectName, location, address, siteInCharge, fromDate, toDate

⚙️ General Notes

All POST & PUT APIs require JWT Authentication

File uploads (MTC, receipts, payslips) → use multipart/form-data

Pagination & Filters can be applied with GET APIs (e.g., /api/products?type=RawMaterial&page=1)
